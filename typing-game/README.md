# TypeRacer ⚡

A browser-based typing speed game. No installation required — just open `index.html`.

## How to play

1. Open `index.html` in any web browser
2. Start typing the displayed passage — the timer starts automatically
3. Complete the passage or wait 60 seconds for your result

## Stats tracked

| Stat | Description |
|------|-------------|
| WPM | Words per minute (correct characters ÷ 5 ÷ elapsed minutes) |
| Accuracy | Percentage of keystrokes that were correct |
| Correct chars | Total correctly typed characters |

Your best score is saved in your browser's local storage.

## Keyboard shortcuts

- `Enter` — restart with the same passage
- `文章を変える` button — load a new passage
